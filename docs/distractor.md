# 방해 그릇 복원 — 목표 선택 단계(S1) 측정

초기 측정에서는 10개 중 9개 태스크에 방해 그릇이 테이블 밖(`[0.34, −0.40]`)에
있었다. task 0 만 참조 위치를 유지했다. 그래서 **목표 선택 단계(S1)를 측정할 수
없었다.**

참조 좌표로 복원하고 500판을 다시 측정했다.

```
1차 (방해 없음)   338/500 (67.6%)
2차 (방해 복원)   349/500 (69.8%)
목표 선택 S1      499/500 (99.8%)
```

---

## 1. 복원 절차

참조 씬의 `akita_black_bowl_2_main` 좌표를 태스크별로 되돌렸다. 받침이 있는
태스크는 받침 표면 높이에 맞춰 z 를 보정했다.

| 태스크 | 방해 그릇 위치 | 비고 |
|---|---|---|
| T0 | 테이블 | 원래 유지됨 |
| T1~T9 | 참조 좌표 | 복원 |

복원 후 목표 그릇과 방해 그릇의 거리는 176 ~ 498 mm 다.

---

## 2. 성능 차이는 없다

| | 1차 (방해 없음) | 2차 (방해 복원) |
|---|---|---|
| 배치 | 338/500 (67.6%) | 349/500 (69.8%) |

T6 는 2차에서 배치 좌표도 함께 바꿨으므로 단독 비교에서 제외한다.

```
T6 제외 9태스크   −2.1 %p   95% CI [−8.1, +4.0]   Fisher p = 0.52
```

**유의하지 않다.** 아무것도 바꾸지 않은 T0 도 45 → 43 으로 2판 움직였으므로
그 정도가 실행 간 잡음이다.

---

## 3. 목표 선택은 거의 완벽하다

```
S1  첫 파지 시점 그리퍼가 목표 그릇 쪽에 더 가까움   499/500 (99.8%)
```

판정은 첫 `CLOSE` 시점의 그리퍼 위치를 목표 그릇과 방해 그릇 중심에서 각각 재어
가까운 쪽을 고른다.

**정책이 잘못된 그릇을 집는 실패는 사실상 없다.** 지시문의 공간 단서
("between the plate and the ramekin", "next to the cookie box")가 제대로
작동한다.

이 수치는 초기 README 의 한계 항목 3번
("방해 그릇이 씬에서 제외됨 — S1 을 측정할 수 없다")을 해소한다.

---

## 4. 근접 조건은 다르다

방해 물체를 목표 가까이 가져가면 떨어진다. T0·T1·T8 에서 거리를 바꿔가며 측정했다.

| 목표–방해 거리 | 배치 |
|---|---|
| 176 ~ 498 mm (참조 복원) | 변화 없음 |
| 125 ~ 300 mm (근접) | 89% → 67% |

근접 조건에서는 방해 그릇이 접근 경로에 들어와 **물리적으로 충돌**한다.
인식 차원의 혼동이 아니라 궤적 간섭이다. 12개 조건 중 8개에서 방해 그릇이
카메라 화면 밖에 있었으므로 인식 효과는 측정하지 못했다.

## 5. 태스크별

| task | 1차 (방해 없음) | 2차 (방해 복원) | S1 (2차) |
|---|---|---|---|
| T0 | 45/50 | 43/50 | 50/50 |
| T1 | 36/50 | 32/50 | 50/50 |
| T2 | 35/50 | 33/50 | 50/50 |
| T3 | 39/50 | 40/50 | 50/50 |
| T4 | 0/50 | 2/50 | 50/50 |
| T5 | 44/50 | 42/50 | 50/50 |
| T6 | 28/50 | 48/50 | 49/50 |
| T7 | 38/50 | 36/50 | 50/50 |
| T8 | 46/50 | 46/50 | 50/50 |
| T9 | 27/50 | 27/50 | 50/50 |
| 합계 | 338/500 | 349/500 | **499/500** |

T6 의 28 → 48 은 방해 그릇이 아니라 **배치 변경** 때문이다. 목표 그릇을
`[0.130, −0.070]` 에서 `[0.074, −0.040]` 으로 옮겼고, 로봇 베이스까지 거리가
0.793 m 에서 0.735 m 로 58 mm 줄었다.

그 민감도는 [작업공간 거리](workspace.md)에 따로 정리했다.

T4 의 0 → 2 는 서랍 앵커 보정 때문이다. 서랍이 열려도 그릇 좌표가 따라가지 않던
문제를 고쳐 들기가 0/50 에서 30/50 이 됐다. 배치는 2/50 으로 여전히 낮다.
