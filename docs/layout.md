# 배치 변화

물체 배치를 흔들면 성공률이 어떻게 되는지, 그리고 어떤 배치가 어려운지를
두 번에 걸쳐 측정했다. 성공률 하락은 재현됐고, **원인 가설 두 개는 모두 기각됐다.**

---

## 1. 무엇을 흔들었나

움직인 물체는 접시, 과자 상자, 목표 물체 셋이다. 라메킨·스토브·캐비닛과
방해 물체(스토브 위 고정)는 건드리지 않았다.

지시문이 참이 되도록 제약을 걸었다.

```
목표 – 과자 상자   "next to" 가 성립하는 범위
방해 – 과자 상자   > 250 mm   (방해가 "next to" 에 해당하면 안 됨)
목표 – 접시        판정 반경(50 mm) 밖
물체 간 거리        접촉 거리 이상
고정 물체와의 여유   135 mm 이상
```

접촉 거리는 실측 치수에서 계산했다.

```
접시 반경 68.8   목표 물체 반경 55.9   과자 상자 반경 57.4 (대각선)   라메킨 반경 45.3

목표–접시    124.7 mm
목표–과자    113.3 mm
접시–과자    126.1 mm
```

첫 시도에서 이 계산을 빼먹어 한 배치가 겹쳤다. 물체를 80 mm 떨어뜨렸더니
접시와 그릇이 서로 밀어내며 17도씩 돌아갔다. 계산을 넣은 뒤로는 전 세트에서
겹침이 없다.

---

## 2. 1차 — 기하학적 난이도 축 (기각)

이송 거리가 길고 이송 경로가 과자 상자에 가까울수록 어려울 것이라고 가정했다.
30세트를 만들어 20개를 쉬움, 10개를 변이로 나누고 세트당 1판씩 돌렸다.

| 축 | 쉬움 (20) | 변이 (10) |
|---|---|---|
| 열 순서 | 접시 – 그릇 – 과자 | 접시 – 과자 – 그릇 |
| 이송 거리 | 146 ~ 225 mm | 288 ~ 344 mm |
| 경로 여유 | 135 ~ 187 mm | 3 ~ 69 mm |

### 결과

| | 배치 성공 | 차이 | 95 % CI | Fisher p |
|---|---|---|---|---|
| 쉬움 | 3/20 (15 %) | | | |
| 변이 | 2/10 (20 %) | −5.0 %p | [−37.5, +20.5] | 1.00 |

**차이가 없다.** 성공한 5세트의 경로 여유는 140, 141, 182, 3, 52 mm로 흩어져 있다.
경로 여유 3 mm짜리가 성공했다.

성공과의 상관도 전부 작다.

```
이송 거리    +0.154
그릇–과자    +0.118
방위각       −0.131
경로 여유    −0.011
```

### 왜 틀렸나

쉬움으로 분류한 20세트가 **접시 – 그릇 – 과자** 순서인데, 학습 배치는
**접시 – 과자 – 그릇**이다. 기하학적으로 쉽게 만든 배치가 정책에게는 더 낯설었다.

---

## 3. 2차 — 학습 배치와의 거리 축 (기각)

학습 배치를 0점으로 잡고 세 물체의 평균 이동량을 난이도 축으로 삼았다.
세트 20은 학습 배치 그대로다.

```
학습 배치   접시 [0.060, +0.200]
            과자 [0.070, +0.030]   ← 접시와 그릇 사이
            그릇 [0.130, −0.070]
```

| 축 | 쉬움 (20) | 변이 (10) |
|---|---|---|
| 평균 이동량 | 0 ~ 77 mm | 117 ~ 223 mm |
| 과자가 사이에 있음 | 18/20 | 0/10 |

이동량이 커지면 배치 관계가 자연스럽게 깨진다. 1차처럼 순서를 인위적으로
뒤집은 것이 아니다.

### 결과

| | 배치 성공 | 차이 | 95 % CI | Fisher p |
|---|---|---|---|---|
| 쉬움 | 3/20 (15 %) | | | |
| 변이 | 2/10 (20 %) | −5.0 %p | [−37.5, +20.5] | 1.00 |

**1차와 같은 수치다.** 평균 이동량과 성공의 상관은 −0.051이다.

**학습 배치 그대로인 세트 20도 실패했다.** 같은 배치를 방해 물체 없이 50판
돌렸을 때는 28/50이었으므로 한 판 실패는 우연일 수 있으나, 30세트 중
23세트가 에피소드 상한(250질의)을 소진했다.

### 최초 실패 단계

| 단계 | 판수 |
|---|---|
| S3 정렬 | 13 (43%) |
| S5 파지 | 6 (20%) |
| S7 이탈 | 6 (20%) |
| S8 이송 | 1 |
| S9 하강 | 1 |
| S10 해제 | 1 |
| 통과 | 2 |

1차에서 S3 실패는 2건이었는데 2차에서 13건이다.

## 4. S3 실패의 정체

방해 물체를 잘못 집는 것인지 확인했다. 첫 파지 시점의 그리퍼 위치를
목표·방해 각각과 비교했다.

```
목표까지   16 ~ 244 mm
방해까지  297 ~ 443 mm
```

30세트 전부 목표 쪽이다. **선택은 문제가 아니다.**

접근 중에 물체를 밀어냈는지도 봤다.

```
물체가 20 mm 넘게 밀린 판   4/30
나머지 26세트               2 mm 이내로 제자리
```

밀림도 소수다.

남는 것은 **정렬 정밀도**다.

```
정렬 오차 분포 (n=30, mm)
16 37 45 48 49 51 52 53 57 58 61 62 67 70 74 75 78 | 82 83 84 85 85 86 86 90 91 98 100 106 244
                                              문턱 80
```

참조는 43~62 mm이고 우리 중앙값은 74 mm다. **참조 최댓값보다 중앙값이 크다.**

성공과의 관계는 뚜렷하다.

| 정렬 오차 | n | 성공 | Fisher p |
|---|---|---|---|
| ≤ 80 mm | 17 | 5 (29 %) | 0.052 |
| > 80 mm | 13 | **0 (0 %)** | |

정렬은 성공의 필요조건이다. 충분조건은 아니다.

## 5. 종속변수를 바꾸자 하나가 남았다

성공은 이진이라 30세트에 성공 5건으로는 어떤 인자도 확인할 수 없다.
정렬 오차를 종속변수로 놓으면 연속값 30개가 되어 통계력이 올라간다.

| 상관 대상 | 전체 (n=30) | 이상치 제외 (n=29) |
|---|---|---|
| 로봇 베이스까지 거리 | **+0.609** | **+0.591** |
| 접근 방위각 | +0.486 | +0.085 |
| 학습 배치 거리 | +0.339 | −0.171 |
| 목표 이동량 | +0.407 | −0.178 |
| 경로 여유 | −0.011 | — |

**거리만 남는다.** 나머지는 이상치 한 세트(정렬 오차 244 mm)에 기대고 있었다.

상세는 [작업공간](workspace.md).

## 6. 결론

```
배치를 흔들면 성공률이 70% 에서 17% 로 떨어진다.  두 실험에서 재현됐다.

기하학적 난이도로는 설명되지 않는다.        상관 0.16 이하
학습 배치와의 거리로도 설명되지 않는다.      상관 −0.05
잘못된 물체를 고르기 때문도 아니다.          30/30 이 목표 쪽
접근 중 물체를 밀어서도 아니다.              4/30

남은 것은 파지 정렬 정밀도다.
80 mm 를 넘으면 0/13, 넘지 않으면 5/17 이 성공했다.
정렬 오차와 유일하게 상관이 있는 것은 로봇 베이스까지의 거리다.
```
