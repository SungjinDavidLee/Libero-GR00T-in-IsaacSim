# 어댑터 규약

정책 출력을 다른 제어기의 언어로 번역하는 계층의 전체 명세다. 정책 가중치와 지시문은 건드리지 않는다.

---

## 1. 정책 인터페이스

### 1-1. 입력

| 채널 | 형식 | 내용 |
|---|---|---|
| `video.image` | 256×256×3 uint8 | 3인칭 카메라 |
| `video.wrist_image` | 256×256×3 uint8 | 손목 카메라 |
| `state.x/y/z` | float | 엔드이펙터 위치 |
| `state.roll/pitch/yaw` | float | 엔드이펙터 자세 (축각) |
| `state.gripper` | float×2 | 손가락 관절 위치 |
| `language.annotation.human.action.task_description` | str | 태스크 지시문 |

보상, 종료 신호, 성공 여부, 물체 좌표는 **들어가지 않는다.**

### 1-2. 출력

16행 × 7열. 각 행이 `[dx, dy, dz, droll, dpitch, dyaw, grip]`이다.

한 번의 관측으로 **16스텝짜리 궤적을 통째로 예측**하는 구조다. 청크 내부는 부드러운 가감속 프로파일을 이룬다. 예를 들어 접근 국면의 `dx` 8행은 `+0.44 → +0.27 → +0.10 → −0.01 → −0.19 → −0.38 → −0.54 → −0.63`처럼 감속으로 이어진다.

어댑터는 앞 8행(`NSUB=8`)을 한 행씩 실행한 뒤 다시 질의한다. 참조의 `n_action_steps=8`과 같다.

---

## 2. 관측 변환

### 2-1. 참조의 전처리

참조 래퍼는 두 카메라 이미지에 `[::-1, ::-1]`을 적용한다. 상하 뒤집기와 좌우 미러가 함께 들어간다.

### 2-2. 이식 측 상태

이식 씬은 3인칭 카메라 출력에 좌우 미러를 이미 적용해 둔 상태였다. 어댑터가 다시 미러하면 상쇄되어 참조와 반대가 된다.

| 채널 | 씬 출력 | 어댑터 설정 | 결과 |
|---|---|---|---|
| 3인칭 | 미러 적용됨 | `FLIP=n` (추가 변환 없음) | 참조와 일치 |
| 손목 | 원본 | `WFLIP=h` (좌우 미러) | 참조와 일치 |

참조 이미지와 나란히 놓고 랜드마크의 화면 위치로 확인했다.

| 화면 | 참조 3인칭 | 이식 3인칭 (`FLIP=n`) |
|---|---|---|
| 왼쪽 | 그릇 · 접시 (world +y) | 동일 |
| 오른쪽 | 캐비닛 · 스토브 (world −y) | 동일 |

| 화면 | 참조 손목 | 이식 손목 (`WFLIP=h`) |
|---|---|---|
| 왼쪽 | 스토브 | 동일 |
| 오른쪽 | 그릇 · 접시 | 동일 |

### 2-3. 카메라 배치

| 항목 | 참조 | 이식 | 검증 |
|---|---|---|---|
| 3인칭 위치 | `[0.65861, 0, 1.61035]` | 동일 | 실행 로그의 `effective_position` |
| 3인칭 화각 | fovy 45° | 45° | 동일 |
| 손목 마운트 | hand 프레임 `[0.05, 0, 0]` | `WX=0.05` | 접시 겉보기 폭 132 px 대 129 px |
| 손목 화각 | — | 75° | 상동 |

손목 카메라를 z축(접근축)으로 옮기면 손가락 사이 또는 손 몸체에 가려 검은 화면이 된다. 측면 오프셋만 가능하다.

### 2-4. 관측 정합 검증

동일 상태·동일 지시문으로 이미지만 바꿔 정책에 직접 질의하고, 참조가 같은 시점에 낸 액션과의 거리를 측정했다. 16회 반복 평균이다.

| 조건 | 액션 거리 | 자체 산포 |
|---|---|---|
| 참조 3인칭 + 참조 손목 | 0.0640 | 0.019 |
| 이식 3인칭 + 참조 손목 | 0.0574 | 0.024 |
| 참조 3인칭 + 이식 손목 | 0.1418 | 0.031 |
| **이식 3인칭 + 이식 손목** | **0.0625** | 0.037 |
| 손목을 3인칭 복제로 대체 | **0.7149** | 0.070 |

3인칭은 참조와 구분되지 않는다. 손목은 잔차가 남지만 위조 대비 5배 작다.

**손목 위조의 위험** — 3인칭이 참조 원본이어도 손목만 위조하면 거리가 11배가 된다. 액션이 `+x +y` 방향으로 강하게 편향되며, 목표가 그 방향에 있으면 성능이 좋아 보이는 인공물이 발생한다.

## 3. 상태 변환

### 3-1. 좌표계

참조와 이식의 엔드이펙터 프레임은 z축 둘레 180° 회전 관계다.

```
R_reference = R_isaac · Rz(π)
```

`QROT=z180`이 이 회전을 적용한다. 적용 전후로 정책 출력 노름이 0.17에서 1.0으로 회복된다.

### 3-2. 그리퍼 초기값

| 항목 | 참조 | 이식 기본 | 조정 |
|---|---|---|---|
| 리셋 직후 손가락 | `[+0.020833, −0.020833]` | `[+0.04, −0.04]` | `GINIT=0.0208` |

이식 기본값은 완전 개방이며, 학습 분포의 상한(q99 = 0.0399)에 걸린다. 정책에 직접 질의해 확인했다.

| 상태 조건 | 액션 거리 |
|---|---|
| 손가락 0.0208 | 0.0510 |
| 손가락 0.0300 | 0.1123 |
| 손가락 0.0400 | 0.3060 |

**6배 차이**다. 위치·자세를 참조 값에서 이식 값으로 바꾸는 것은 영향이 없었다(0.057 대 0.051). 그리퍼 개방폭 하나가 지배적이다.

## 4. 행동 변환

### 4-1. 위치

```
target = current_hand_pose
       + clip(a[0:3], -1, 1) · [PSCALE·PXSC, PSCALE·PYSC, PSCALE]
       + [0, 0, ZFF]
```

목표는 매 substep 실측 손 위치에서 다시 잡는다. 도달하지 못한 잔여분은 누적하지 않는다.

| 파라미터 | 값 | 근거 |
|---|---|---|
| `PSCALE` | 0.0245 | 개루프 재생, 이동비 1.00 |
| `PXSC` | 0.91 | x축 잔차 1.10 보정 |
| `PYSC` | 1.18 | y축 잔차 0.87 보정 |
| `ZFF` | 0.0003 | z축 잔차 1.41 보정 (중력 처짐) |

### 4-2. 자세

```
QC ← normalize( axis_angle_to_quat(a[3:6] · RSCALE) ⊗ QC )
QC ← slerp_clamp(QC, Q0, RMAX)
```

누적 방식이며 실측 자세를 되먹이지 않는다. `RMAX`는 초기 자세 `Q0` 기준 원뿔 제한이다.

**이 계층은 개루프 정합을 하지 못했다.** 상태의 roll이 π 근처라 축각 표현이 퇴화하고, 변화량 기반 지표가 성립하지 않는다. `RSCALE=0.5`, `RMAX=0.5`는 기존 값을 승계했다.

실측 자세를 기준으로 삼는 방식(`RBASE=meas`)은 두 차례 시험했고 모두 발산했다. 떨림 위에 새 목표가 쌓여 증폭된다.

### 4-3. 역기구학

Lula IK를 호출하고, 실패 시 4단계로 완화한다.

```
frac  1.0 → 0.5 → 0.25 → 0.125     (목표 변위 축소)
자세  tgt_q → QC → Q0               (자세 제약 완화)
```

500 에피소드에서 IK 실패는 사실상 발생하지 않았다.

### 4-4. 그리퍼

참조는 액션의 7번째 성분을 `sign()`으로 이진화해 매 스텝 적용한다.

이식은 **청크 8행의 평균**으로 이진화한다(`GCHUNK=1`).

| 방식 | 결과 |
|---|---|
| 행별 이진화 | 청크 안의 단일 스파이크로 파지 1스텝 만에 개방. 그리퍼 난발 |
| 청크 평균 | 안정. 무관 물체 교란 최대 0.034 m 대 0.270 m |

**참조에 없는 장치다.** 위치 제어 그리퍼가 3 물리스텝 만에 완전히 열리기 때문에 필요해졌다. 참조의 힘 제어 그리퍼는 액추에이터가 느려 단일 스텝 명령으로 완전 개방되지 않는다.

## 5. 제어 주기

| 항목 | 참조 | 이식 |
|---|---|---|
| 정책 질의당 액션 | 8행 | 8행 |
| 액션 1행당 물리 | 20 × 0.002 s | 3 × 0.0167 s |
| 질의 간격 | 0.4 s | 0.4 s |
| 액션 1행당 도달률 | 스텝 내 도달 | 33 ~ 50% |

주기는 같고 도달률이 다르다. 그 차이를 스케일이 흡수한다.

`NSUB=4`(청크 앞 4행만 사용)를 시험했으나 나빠졌다. 청크가 가감속 프로파일이라 앞부분만 쓰면 전진량이 줄고, 정책이 계획한 동작 단위가 절반에서 잘린다.

---

## 6. 종료 규약

참조 환경은 성공 술어가 성립하는 순간 에피소드를 끝낸다. 이식 환경에는 그 장치가 없어 새로 만들었다.

| 장치 | 동작 |
|---|---|
| `TERMREF` | 배치 조건 성립 시 종료 절차 진입 |
| `TERMHOLD` | 팔을 고정하고 물리 2초 진행 후 재확인. 실패 시 판정 취소 후 계속 |
| `RETWAIT` | 종료 전 최대 N질의 대기. 정책이 스스로 물러나는지 관측 |

**전부 참조에 없는 장치다.** 다만 스크립트로 팔을 움직이지는 않는다. 후퇴 동작은 정책이 낸 것만 기록한다.

---

## 7. 참조에 없는 요소 정리

공표 시 명시가 필요한 항목이다.

| 요소 | 성격 | 이유 |
|---|---|---|
| `PXSC` · `PYSC` | 축별 스케일 보정 | 관절 배치·중력에 따른 축별 전달률 차이. 개루프 실측에서 유도 |
| `GCHUNK` | 청크 단위 그리퍼 이진화 | 위치 제어 그리퍼의 응답 속도 차이 |
| `TERMREF` · `TERMHOLD` | 종료 판정 | 참조는 환경이 종료. 이식 환경에는 해당 장치가 없음 |
| `RETWAIT` | 후퇴 관측 구간 | 판정 시점 이후의 정책 거동 기록용 |
| `SETTLEQ` | 기준 좌표 정착 대기 | 물체가 리셋 직후 낙하하므로 정착 후 기준을 잡음 |

사용하지 않은 것: 파인튜닝, 참조 궤적 재생을 통한 성공 유도, 태스크별 위치 오프셋.
