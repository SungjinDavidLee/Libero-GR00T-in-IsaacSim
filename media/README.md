## 주의

이식 환경의 영상은 **정책 질의당 1프레임**으로 기록된다. 참조 영상은 env-step마다 기록되므로 약 8배 조밀하다.

같은 궤적이라도 이식 측 영상이 훨씬 격하게 보인다. 두 영상의 부드러움을 직접 비교하면 안 된다. 질의당 실제 변위는 이식 79 mm, 참조 75 mm로 5% 이내다.
